# Pirate RPG

Nouveau projet Godot 4 remplaçant l'ancien prototype Ninja.

## Première fondation jouable
- monde 3D tropical original
- caméra inclinée à 60°
- déplacement 360°
- village côtier, plage, mer et port
- taverne pirate et bureau de la Marine
- choix de faction Pirate / Marine
- HUD et première quête « Choisis ta voie »

Le contenu actuel est une fondation fonctionnelle. La prochaine étape est d'augmenter fortement le niveau de détail de l'île, puis d'ajouter interactions, combat et contrôles tactiles.
