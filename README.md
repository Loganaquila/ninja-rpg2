# Ninja RPG 2
Prototype navigateur mobile-first d’un RPG ninja original en vue du dessus.

## Contrôles
Déplacement exclusivement au clic/toucher.

## Développement
```bash
npm install
npm run dev
```

## V0.1
- Monde 4096×4096
- Grande capitale ninja procédurale
- caméra suiveuse
- HUD mobile
- Tour du Conseil et terrain d’entraînement

Les prochaines étapes sont les interactions, missions, progression de rang, techniques par parchemins et combat tactique.
